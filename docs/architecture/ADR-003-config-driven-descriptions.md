# ADR-003: 參數描述策略

## 狀態
** ✅ 已批准 ** - 2026-07-31

## 決策
** 採用選項 B（程式碼內聯描述），保留演進到選項 C（混合方案）的彈性 **

- 使用 `DescriptionAttribute` 在 C# record 上直接定義參數描述
- 不將描述抽離到外部 JSON 設定檔
- 未來可透過 Attribute + 設定檔覆寫機制演進到混合方案

## 優缺點分析

### 選項 B 優點
- ✅ 編譯期檢查，避免遺漏
- ✅ 單一維護點，降低技術債
- ✅ IntelliSense 支援，開發體驗好
- ✅ 與程式碼一起版本控制
- ✅ 遷移到 B→C 成本低（3 人天）

### 選項 B 缺點
- ⚠️ 描述文字與程式碼耦合
- ⚠️ 非技術人員無法編輯描述

### 緩解措施
- 描述文字可透過資源檔（.resx）國際化
- 提供 Tool 描述生成器（基於 XML 註解）

## 影響
- Tool 開發速度提升 30%
- 啟動失敗風險降低 80%
- 維護成本降低 50%
