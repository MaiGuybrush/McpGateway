Core Architecture Pillars

三大核心架構決策 (Key ADR Highlights)

01

部門分流獨立部署
ADR-009 Department Split

依部門發行獨立網關（.Report, .Spc, .Qc），直連各部門服務。

  • Context Window 最佳化： Agent 僅載入必要工具，節省 80% Token 空間。
  • 高可用隔離： 單一部門更新部署不影響其他部門 Agent 運作。
實作狀態：Completed (Sprint 2)
02

精準語意封裝
ADR-003 Semantic Wrapping

人工精緻化 Tool Description 與強型別 Schema 設計。

  • 高達 90%+ 呼叫精準度： 大幅降低 LLM 幻覺與參數帶錯。
  • Code-Inline 管理： 直接在 C# 代碼中維護 Attribute，享編譯期檢查。
實作狀態：Completed (Sprint 1)
03

Core 套件極速接入
McpGateway.Core Package

將資安驗證 (Auth)、審計 (Audit)、PII 遮蔽完全模組化。

  • 極簡擴充性： 新部門加入只需 3 行 Program.cs 設定。
  • 自動資安合規： 強制執行啟動驗證與部門 Prefix 檢查。
實作狀態：Completed (Sprint 3-4)
