## The one thing to know before anything else

**The PoC never produced working code.** `PoC-REPORT.md` said "✅ COMPLETED" and cited
accuracy/latency numbers as if measured. A code audit this session found:

- `src/McpGateway/Infrastructure/` did not compile (two conflicting `ITool` interfaces, a
  constructor type mismatch, references to undefined types) — **now deleted**, see below
- `ModelContextProtocol.AspNetCore` (required for Streamable HTTP) was never referenced
- All accuracy/latency/ROI figures are estimates — `PoC-REPORT.md:375` says so itself
- Dev machine only has .NET SDK 3.1.402; the project targets `net8.0`

This is not a regression to fix — it's the starting point. Treat **Sprint 0** (below) as
mandatory, not a formality. This finding is fully documented in
`docs/specs/development-plan.md` §0 and annotated inline in `PoC-REPORT.md` and
`DELIVERABLES.md`.

## What's next: Sprint 0 (the gate)

Per `docs/specs/development-plan.md` §2 — **5 person-days, and nothing after it should start
until it passes**:

1. Install .NET 8 SDK (machine currently has 3.1.402 only)
2. Build a minimal *working* MCP server using the real
   `ModelContextProtocol` + `ModelContextProtocol.AspNetCore` packages
3. Confirm two specific unknowns:
   - Does `MapMcp` support mounting at a path prefix (`/report`, `/spc`)? This is the load-bearing
     assumption behind ADR-009's ingress routing (D4). If not, the plan falls back to
     hostname-based routing — described in the ADR as an alternative, not a dead end.
   - Is Attribute-based tool registration (not the "dynamic registration" the original
     design doc assumed) sufficient? Design-doc v1.1 already simplified this away, so risk
     here is low — but confirm before building on it.
4. Take the first *real* latency measurement (single service, no ingress)
5. Confirm the internal NuGet feed can publish/restore `McpGateway.Core`

Gate-failure fallbacks for each of these are written out in `development-plan.md` §2 — don't
rediscover them, they're already reasoned through.
